## Question

Can we build the published idea of a Berlekamp-Massey decoder whose history is reconstructed instead of stored, and
does it beat our Lanczos decoder (ratio 6.81)?

## Setup

This entry was backfilled from the study note and git history on 2026-11-15. Idea: Gu, Kemeny, Yelin, Lukin
(arXiv:2610.22367 SI I.1); the andigu/uncompute repository states Apache-2.0 and nothing was copied from it; the public
DQI lineage has no licence. Code: `src/dqi_gen/bm.py`, `bmref.py`, `tests/unit/test_dqi_bm.py`. It is our divstep
decoder with the 945-qubit dialog replaced. Small instances first, then Kaggle (`qcc-dqi-gen`, official verifier,
102,400 shots per salt). Ten-salt circuit built from commit `9d9d652`, kept at
`~/qcc-circuits/dqi/dqi-bm-1855q-d25804a5a5c6.kmb` (outside git).

## Results

### Quantitative

| Full-size version | Qubits | Toffolis | Worst-salt cost | Ratio | Salts |
|---|---:|---:|---:|---:|---|
| first build (PR 114, `090fb7f7`) | 1,874 | 1,120,442 | 4.7593e12 | 5.13 | 5/5 PASS |
| rank-42 products, tower inversion, step-bounded widths (PRs 116, 118, `b72bd806`) | 1,867 | 740,602 | 3.1490e12 | 7.76 | 5/5 PASS |
| `sg` released during Forney division (PR 124, `d25804a5`) | 1,855 | 740,602 | 3.1087e12 | 7.86 | 10/10 PASS |

Zero failures everywhere (R = 1.19). Ten salts: 0 to 4 worst 3.1087e12, 5 to 9 worst 3.1003e12. Static counts matched
the prediction `narrow + 4,024 x per-position` to the Toffoli [M]. `bench promote dqi --dry-run` answers BLOCKED: the cost
3.10871e12 is not below the current best 3.77872e11, so the cost gate fails (the frontier is 8.2x cheaper). Not promoted.

### Qualitative

* Ties replace in the swap rule, so generic inputs never take a retain step (3 of 300 weight-law shots); with an invariant
  `g[0] * b = 1` a swap is recognised from the after-state and neither the swap bit nor the quotient is stored. Row widths
  follow the locator degree.
* Bug found: in the reverse pass the stack flag must be cleared before the quotient is applied, otherwise 50% phase errors
  with 0 value errors, hidden by measurement-based clears.
* Small fields cannot judge failure rates (q = 16 or 64 fail from ordinary degeneracy); `mid12`, `narrow`, `full` count.
* The small levers (narrowing `shift_f`, folding quotient and recomputation, Omega in place) are worth 1 to 3% each, so only
  zero-Toffoli qubit trims were taken. The scan is 52% of the Toffolis.
* The projected next lever, a reciprocal-polynomial scan (about 23 per position, saving about 290k Toffolis, ratio 11 to 12),
  was not built here; see the follow-up entry, which finds its in-place version a dead end.

## Decision

Best own DQI so far (ratio 7.86, Lanczos 6.81), not promoted. Next: the reciprocal-polynomial scan, which needs an in-place
Euclid in the 35 zero syndrome words with a fixed schedule. A second BM run on `O / E` was costed (+430 qubits) and loses.
