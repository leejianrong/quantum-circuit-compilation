## Question

How is syed3000's 889-qubit DQI circuit put together, in our own words, and can we rebuild each part from standard algebra so
that our own generator reaches the frontier?

## Setup

This entry was backfilled from the study note and git history on 2026-11-15. Source: the Apache-2.0 dataset
`vqcc-own-circuit-portfolio` (425 files, 46k lines of Python, a pinned controller with hash-pinned review records), read as a
reference; no code was copied. Our classical model is `src/dqi_gen/thiele.py` (`tests/unit/test_dqi_thiele.py`). Full-size runs
on Kaggle, official verifier, 5 salts. Commit: not recorded. The lineage is described in `docs/PROVENANCE.md`.

## Results

### Quantitative

| Build | Qubits | Toffolis | Worst-salt cost | Ratio |
|---|---:|---:|---:|---:|
| Gu port (`rs`, `rs_build.py`), full size | 1,837 | 444,030 | 1.828e12 | about 13.4 |
| own `thiele` generator, full size | 955 | 615,399 | 6.717e11 | 36.4 |
| `fixed` (convert plus scan), narrow, 2,048 shots | 903 | 345,875 | n/a | n/a |
| `fixed` with seeded synthesis, narrow | 890 | 346,192 | n/a | about 66 (static estimate, about 390.5k Toffolis) |

All full-size rows PASS at 5 salts with zero failures [M]; the `thiele` static prediction (615k) matched. Gu port: build 661 s,
verify 1,522 s, 18.3 GB peak. `thiele`: build 97 s, verify 739 s, 5.2 GB peak. The GF(2^24) multiplier costs exactly 99 Toffolis
and 3 ancillas, exact on 576 basis pairs and 3,000 random pairs [M]. Classical Thiele pass: weights 1, 3, 19, 28, 35 recover the
planted word; 0 failures in 600 weight-law draws (expected about 35 / 2^24 per shot) [M].

### Qualitative

* The algorithm [V, read from the source, stated in our words]: a linear residue map sends the syndromes to 35 words of 24 bits;
  an in-place Thiele extraction treats each pivot as a GF(2^24) element, so a premature zero has probability about 2^-24 (the
  failure-free mechanism); synthesis rebuilds the polynomials from the heads; convert uses a fixed-shape Euclid on the
  half-degree pair; the scan is only a zero test (11 Toffolis) because the phase is linear in the coefficients; everything is
  mirrored with measurement-based erasure.
* The 864 base qubits plus a 24-bit carry give a peak of 889 to 890. The reverse of extract is 97k against 55k forward because
  it repays masks it measured.
* Each building block is standard algebra: the rank-99 multiplier uses the same recipe as our rank-42 one (degree 6 over GF(16),
  11 points, two-level Karatsuba); nodes share one ring so the head map is one in-place CNOT map; division by `q_i(alpha_l)` is by a
  public constant.
* The in-place pass needs a "normalise by 1/n" move and deferred phases; the public design spends a 195-Toffoli deferred inverse,
  264-Toffoli affine phases and about 43k extra Toffolis in the reverse. The note's step 3 was analysis at the time of writing.
* Seeding the synthesis from the carry word removed an extra word (903 to 890 qubits), the route to the 890 floor.
* The tail controller uses a public cutoff `j_min = 15`; the note says the weight law has no mass below 19 [V].

## Decision

Realistic first milestone was a verified full-size rebuild of the same architecture (ratio about 67 predicted). Next: wire the
remaining stages, check each against `thiele.py`, then look for where the reverse of extract and the spare qubits can beat it.
The Gu port stands as the verified reference (13.4) that the own decoder had to beat, and it did (36.4).

## Reproduce

The note gives no command beyond `--gen thiele` and `--gen fixed` in `dqi_gen.instances`, and the Kaggle kernel `qcc-dqi-gen`.
