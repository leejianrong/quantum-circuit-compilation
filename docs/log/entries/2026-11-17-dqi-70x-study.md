## Question

Where does the public 70.04x circuit (`00ac37d4`) beat our `fixed4` (67.30x)?

## Setup

Kaggle kernel `qcc-dqi-study-public` runs `dqi_gen.study` (counts only) on both circuits; our `fixed4` narrow instance is built
locally with stage tags to locate the CSWAPs. Public circuit read as data, not executed.

## Results

### Quantitative

Static Toffoli-like gates: 384,762 against 368,991 (15,771 T, 4.1%). By type: `CSWAP` 12,384 against 0; `CCX` +2,344;
`CCZ` +1,043 [M]. The public circuit runs 5x the `PUSH_CONDITION` and `BIT_INVERT` instructions and 13x the `BIT_STORE0`
[M]. 92% of our CSWAPs are in the outer's window transposes (5,688 forward, 5,688 undo) [M].

### Qualitative

The vendored window `route()` uses a quantum flag with `cswap`; the same file has a measured-flag `release()` with a deferred
phase debt. The public circuit most likely routes under a measured flag [I]. The adaptive gauge scan (759 T) is small beside it.

## Decision

S5 (QCC-63) becomes: measured-flag routing in the outer window, narrow first, then Kaggle. Predicted ratio about 69.5x
from the CSWAP removal alone.

## Reproduce

`uv run bench kaggle run notebooks/dqi_study_public`; the CSWAP location by `instances.build("fixed4", INSTANCES["narrow"], stage_log=...)`.
